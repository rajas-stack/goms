# Business reference

Use one section or separate file for each supplied list or business rule. No additional department or employee data has been invented here.

## Record format

Topic:

Date supplied:

Details:

## Changes

Record the date, changed values and reason when updating an agreed reference. Preserve relevant reporting relationships and team memberships when updating employee lists.
