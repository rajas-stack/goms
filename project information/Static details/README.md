# Static business details

Keep information supplied by the business here: employee rosters, team structures, department lists, portal lists, naming conventions and agreed business rules. These are editable reference documents, separate from the generated technical documentation.

| File | Contents |
| --- | --- |
| [Employee lists.md](<Employee lists.md>) | Sales, Pre-sales, Bid and Legal roster snapshots with source references |
| [Employee lists.json](<Employee lists.json>) | The same source roster records in a structured format |
| [Business reference.md](<Business reference.md>) | A place to record further supplied lists and rules |

For every new list, record its source, date supplied, owner if known and any approval status. Keep unknown values marked as unknown; do not infer employee details. Editing these files does not update application data. The technical reference generator leaves this folder untouched.
